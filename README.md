# 💰 PocketTrack

**PocketTrack** is a personal finance management app built with **Flutter** that helps users track their income and expenses, monitor their balance, and understand their spending habits through statistics.

## 📱 About

PocketTrack provides a simple and user-friendly way to manage daily finances. Users can record income and expenses, organize transactions by category, view transaction history, and analyze their financial activity through statistics.

## ✨ Features

* 💵 Add and manage income
* 💸 Add and manage expenses
* 🏷️ Categorize transactions
* 📅 Select transaction dates
* 📝 Add optional notes
* 📊 View financial statistics
* 💰 Track total balance
* 📈 Compare income and expenses
* 📋 View transaction history
* ✏️ Edit transactions
* 🗑️ Delete transactions
* 📱 Responsive and user-friendly UI

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**
* **State Management**
* **Local Data Storage**

## 📂 Main Sections

### 🏠 Dashboard

Displays an overview of the user's financial activity, including balance, income, and expenses.

### 💸 Expenses

Users can add expenses by entering the amount, title, category, date, and optional note.

### 💵 Income

Users can record money received, such as salary, freelance income, gifts, or other sources.

### 📊 Statistics

Provides an overview of spending and income to help users understand their financial habits.

### 📋 Transactions

Displays recorded income and expenses in an organized transaction history.

## 🎯 Purpose

The main goal of PocketTrack is to make personal finance tracking **simple, organized, and easy to understand**.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or a physical Android device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/pockettrack.git
```

2. Navigate to the project:

```bash
cd pockettrack
```

3. Get the dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
